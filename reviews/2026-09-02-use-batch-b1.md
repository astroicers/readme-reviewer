## 真實使用誤判收集(隨批入帳)

1. **H-005 emoji 標題 slug 假陽性 ×23**(backup-worker):`## 📖 概述` → GitHub 實際 anchor `#-概述`(emoji 移除後的**前導空白轉 hyphen,GitHub 不 trim**),我們 `strip()` 後算 `概述`。條文自記的「emoji 標題 slug 未實測」已知近似,**首次被真實語料否證**;ground truth = 作者從 GitHub UI 抄的 TOC(與 public-apis 案同型)。
2. **S-001 對兩種下載執行形全盲**(AI-SOP-Protocol):`bash <(curl …)` 行程替換 ×4、PowerShell `irm … | iex` ×2,lint security 報 **0**——`PIPE_TO_SHELL` 只認管道形。實測三句對照:管道形命中、行程替換與 iex 皆 False。
3. **R-005 散文匿名縫真實重現 ×4**(AI-SOP-Protocol、asp-ng、eks-infra、security-weekly-mcp;連同 skill-quality-research 案累計 5 次;blog 是反例——標題+品牌域即可指認)——批次 #3 第 8 列活化。
4. **「自動更新 badge」沒有排除 static shields 假 badge**(backup-worker):`img.shields.io/badge/Tests-52%2F52` 是寫死數字扮成 badge,equivalent_forms 的措辭會讓判讀者誤計為機械同步——需要「動態 badge(服務端渲染)才算」的判別字。
5. **繼承縫真實開火紀錄**:量詞/「宣稱即陳述」(AI-SOP `Python 3.10+`、blog `limit 100`)×2;無陳述分支的「一個裸 vs 滿篇」(security-weekly-mcp 471)×1——皆為批次 #3 既有列的活化證據。
